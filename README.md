# Podia Landing Page Clone 🚀

A responsive, pixel-conscious clone of the Podia landing page built to master utility-first CSS, flexible layouts, and interactive UI components without heavy framework dependencies.

🔗 **[View Live Demo](https://emmanuelsomto.github.io/Tailwind-CSS/)**

---

## 📌 Features

- **Responsive Grid & Flexbox Layouts:** Seamless transitions across mobile, tablet, and desktop viewports using Tailwind CSS breakpoints.
- **Mobile Navigation Drawer:** Interactive hamburger menu built with Vanilla JavaScript for clean mobile navigation.
- **Optimized UI Interaction:** Tactile touch feedback using `active:` states for mobile devices alongside hover animations for desktop navigation.
- **Semantic HTML5:** Built using semantic markup (`<main>`, `<nav>`, `<section>`) for improved accessibility and structure.
- **Asset Integration:** Custom styled inline SVGs and flexible image containers.

---

## 🛠️ Tech Stack

- **HTML5:** Structuring page content and accessibility
- **Tailwind CSS:** Utility-first styling and layout configuration
- **JavaScript (Vanilla ES6):** DOM manipulation for mobile menu toggling
- **Git & GitHub Pages:** Version control and public deployment
